Entry for the make.fun bounty
[The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1):
a program that writes one resignation letter, exactly one line long,
whose only job is to be funny, to `/output/entry.txt`.

## The line

> Effective today, I resign — the job description said 'fast-paced environment', not 'haunted house with Wi-Fi'.

110 characters — inside the 1–140 character gate.

The joke is the gap between the advert and the reality: the job
description promised a "fast-paced environment", and the job turned
out to be a haunted house with Wi-Fi. One sentence, one specific
voice, no padding — the kind of line a colleague would forward to the
group chat, and a letter a person could actually send.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`, deterministically — the same bytes on every
run. Stdlib only, no network. The output directory itself is never
removed, only its contents.
